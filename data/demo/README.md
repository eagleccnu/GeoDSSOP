# Demo data

The executable demo is stored in `examples/minimal_example` so its inputs and
expected output remain together.

- PDB 1UBQ coordinate data: wwPDB/RCSB PDB, CC0 1.0.
- FASTA: chain-A polymer sequence from the same entry.
- ESM-2 features: derived from the pinned MIT-licensed ESM-2 model and verified
  against the FASTA SHA-256.

See `docs/DATA_AND_LICENSES.md` for URLs, hashes, and attribution guidance.
